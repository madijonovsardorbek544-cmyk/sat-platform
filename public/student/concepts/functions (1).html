01 Formulas
Function notation
\(y = f(x)\)
\(f(x)\) means "the output when the input is \(x\)"
Evaluating a function
substitute the input for every \(x\)
If \(f(x)=x^2+1\), then \(f(3)=3^2+1=10\)
y-intercept
y-intercept \(= f(0)\)
If \(f(x)=5x-2\), the y-intercept is \((0,-2)\)
x-intercept (zero / root)
solve \(f(x) = 0\)
If \(f(x)=(x-3)(x+1)\), the zeros are \(x=3\) and \(x=-1\)
Domain
the set of allowed inputs \(x\)
\(f(x)=\dfrac{1}{x-2}\) has domain \(x \neq 2\)
Domain red flags
denominator \(\neq 0\)  ·  even root \(\geq 0\)
\(\sqrt{x-5}\) requires \(x \geq 5\)
Range
the set of possible outputs \(f(x)\)
\(f(x)=x^2\) has range \(y \geq 0\)
Composite functions
\((f \circ g)(x) = f(g(x))\)
Always work from the inside out
Order matters
\(f(g(x)) \neq g(f(x))\)
in general — check which function is "inside"
Unknown constants
plug in a known point to solve
If \(f(x)=ax+5\) and \(f(2)=13\), then \(a=4\)
Average rate of change
\(\dfrac{f(b)-f(a)}{b-a}\)
equals the slope of the line between the two points
Vertical shift
\(f(x) + k\)
shifts the graph up \(k\) units (down if \(k<0\))
Horizontal shift
\(f(x - h)\)
shifts the graph right \(h\) units (left if \(h<0\))
