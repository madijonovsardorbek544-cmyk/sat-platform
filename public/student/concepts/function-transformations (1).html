Function Transformations

Vertical & Horizontal Shifts · Reading Translations

How adding, subtracting, or substituting inside f(x) moves its graph up, down, left, or right — plus the "set it to zero" trick for reading any horizontal shift instantly. Diagram and rules first, then worked examples and a 10-question practice set (3 easy · 3 medium · 3 hard · 1 extreme).

01 Techniques
y = f(x) — original f(x)+a — shifts up f(x)-a — shifts down f(x+a) — shifts left f(x-a) — shifts right
Add to f(x) → shifts the graph UP
\(y=f(x)+a\)
\(y=x^2+2x+2\) sits 2 units above \(y=x^2+2x\)
Subtract from f(x) → shifts the graph DOWN
\(y=f(x)-a\)
\(y=x^2+2x-2\) sits 2 units below \(y=x^2+2x\)
Add inside f( ) → shifts the graph LEFT
\(y=f(x+a)\)
\(f(x+1)\) is 1 unit to the left of \(f(x)\)
Subtract inside f( ) → shifts the graph RIGHT
\(y=f(x-a)\)
\(f(x-1)\) is 1 unit to the right of \(f(x)\)
The "set it to zero" trick for horizontal shifts
\(f(\text{expr}) \Rightarrow \text{solve expr}=0 \text{ for } x\)
\(f(3x-2)\): \(3x-2=0 \Rightarrow x=\tfrac{2}{3}\) → shift right \(\tfrac23\) unit
Order of combined shifts doesn't matter
\(f(x+a)-b\)
Left 5 then down 3 = down 3 then left 5 — same graph
Reflections
\(f(-x)\): flip over y-axis. \(-f(x)\): flip over x-axis
If (3,3) is on \(f\), then (3,-3) is on \(-f(x)\)
Vertical stretch / compression
\(y=a\cdot f(x)\): \(|a|>1\) stretches, \(0<|a|<1\) compresses
If \(f(5)=4\) and \(g(x)=3f(x)\), then \(g(5)=12\)
