Other Types of Equation Questions

Matching Terms · Solution Counting · Absolute Value

How to match coefficients between equivalent expressions, tell infinitely-many-solutions equations apart from no-solution equations, and solve absolute value equations — including the never-negative trap. Rules first, then worked examples and a 10-question practice set (3 easy · 3 medium · 3 hard · 1 extreme).

01 Techniques
Match corresponding coefficients
\(Ax^2\!+\!Bx\!+\!C \equiv Dx^2\!+\!Ex\!+\!F \Rightarrow A\!=\!D,\ B\!=\!E,\ C\!=\!F\)
\((x+10)(x+b) \equiv x^2+3bx+c\)
Infinitely many solutions = identical sides
\(ax+b=cx+d\) has \(\infty\) solutions \(\iff a=c,\ b=d\)
\(6(x+2)=6x+12\) is true for every x
No solution = same slope, different constant
\(ax+b=ax+d,\ (b\neq d) \Rightarrow \text{no solution}\)
\(3x+6=3x+10 \Rightarrow 6=10\) (false)
Absolute value splits into two cases
\(|A|=k\ (k>0) \Rightarrow A=k \text{ or } A=-k\)
\(|x+3|=8 \Rightarrow x=5 \text{ or } x=-11\)
Absolute value equal to 0 → only one solution
\(|A|=0 \Rightarrow A=0 \text{ (single case)}\)
\(|x-10|=0 \Rightarrow x=10\) only
A square or absolute value can never be negative
\(A^2=k \text{ or } |A|=k,\ k<0 \Rightarrow \text{zero real solutions}\)
\(x^2=-4\) → zero real solutions
Quick classifier for linear equations
\(ax+b=cx+d\): \(a\neq c \to \) one solution
Same slope decides ∞ vs. 0 by comparing constants
|expr| = negative constant → no solution
\(|A| = k,\ k<0 \Rightarrow \text{no solution}\)
\(|2x-1| = -5\) → no solution
