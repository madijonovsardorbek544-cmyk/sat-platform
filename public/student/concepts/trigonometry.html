Trigonometry

SOH-CAH-TOA · Complementary Angles · The Unit Circle

Sine, cosine, and tangent as right-triangle ratios; the complementary angle shortcut that skips finding the actual angle; and the unit circle, which extends trig functions to any angle using reference angles and the ASTC sign rule. Diagrams and rules first, then worked examples and a 10-question practice set (3 easy · 3 medium · 3 hard · 1 extreme).

01 Techniques
sin x° = opposite ⁄ hypotenuse · cos x° = adjacent ⁄ hypotenuse · tan x° = opposite ⁄ adjacent
135° terminates in QII, so sine is positive · reference angle to the x-axis is 180°−135°=45°
SOH-CAH-TOA — the basic right-triangle ratios
\(\sin=\dfrac{opp}{hyp},\ \cos=\dfrac{adj}{hyp},\ \tan=\dfrac{opp}{adj}\)
5-12-13 triangle → \(\sin x°=\tfrac{5}{13},\ \cos x°=\tfrac{12}{13},\ \tan x°=\tfrac{5}{12}\)
Complementary angle shortcut
\(\sin(x°)=\cos(90°-x°), \quad \cos(x°)=\sin(90°-x°)\)
\(\sin(50°)=\cos(40°)\)
Unit circle definitions — work for ANY angle
\(\cos\theta=x, \quad \sin\theta=y, \quad \tan\theta=\dfrac{y}{x}\)
the point where the angle terminates has coordinates \((\cos\theta,\sin\theta)\)
Reference angle — the angle's distance from the x-axis
\(\text{ref. angle} = \text{shortest angle to nearest x-axis}\)
330° → \(360°-330°=30°\); 135° → \(180°-135°=45°\)
ASTC — sign of each function by quadrant
\(\text{QI: All +}, \ \text{QII: Sin +}, \ \text{QIII: Tan +}, \ \text{QIV: Cos +}\)
"All Students Take Calculus"
Coterminal angles land on the same point
\(\theta \pm 360°k \ (\text{or} \pm 2\pi k)\)
\(1{,}575° - 4(360°) = 135°\)
Quadrantal angles have obvious coordinates
\(0°\!=\!(1,0),\ 90°\!=\!(0,1),\ 180°\!=\!(-1,0),\ 270°\!=\!(0,-1)\)
\(\sin(270°)=-1,\ \cos(270°)=0\)
Special right triangle ratios (needed for reference angles)
\(30\text{-}60\text{-}90: 1:\sqrt3:2 \qquad 45\text{-}45\text{-}90: 1:1:\sqrt2\)
hypotenuse = 1 (unit circle) → legs \(\tfrac12\) and \(\tfrac{\sqrt3}{2}\)
On the real test, use your calculator
\(\text{compare Desmos' decimal to each answer choice}\)
even for "exact" answers like \(\tfrac{\sqrt3}{2}\), decimals are faster
