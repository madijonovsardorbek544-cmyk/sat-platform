01 Formulas
The one rule that matters most
flip the sign ONLY when you multiply or divide both sides by a negative number
seeing a negative number is not enough — you must actually multiply/divide by it
Graphing y > or y < a line
y > line → shade above  ·  y < line → shade below
think of y as "the point must be higher/lower than the line"
Solid vs. dashed line
strict (\(<,>\)) → dashed  ·  non-strict (\(\leq,\geq\)) → solid
dashed = points on the line are NOT solutions
Testing a point
plug \((x,y)\) directly into the inequality
true statement → it's a solution  ·  false → it isn't
Compound (3-part) inequalities
\(a < \text{expression} < b\)
do the same operation to all three parts at once
Systems of inequalities
solution region = where ALL shaded regions overlap
a point must satisfy every inequality in the system, not just one
Word-problem keywords
"no more than / at most" → \(\leq\)
"at least / no less than" → \(\geq\)
Equation + inequality combo
isolate a variable in the equation
substitute it into the inequality to get one inequality in one variable
Rounding for min/max
minimum → round UP  ·  maximum → round DOWN
whole-number answers can't be a fraction of an item
Limiting resource
check each resource separately
the SMALLER max is the real limit — that resource runs out first
Two-inequality systems
substitute the boundary of one variable into the other
to maximize one variable, use the extreme (boundary) value of the other
Adding inequalities
only ADD inequalities — never subtract
scale one first if needed so a variable's coefficients line up, just like elimination
WATCH OUT — Working with a negative number is not the trigger. Only the act of multiplying or dividing both sides by a negative number flips the sign. Subtracting a negative, or having a negative constant sit on one side, changes nothing.
