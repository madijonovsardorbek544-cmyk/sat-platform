01 Formulas
What is a system?
2+ equations sharing the same variables
the solution is the (x, y) that satisfies all of them at once
Substitution
isolate one variable, plug it into the other equation
best when a variable already has no coefficient
Elimination
scale an equation so a variable's coefficients match
then add or subtract to cancel that variable
Choosing a method
no-coefficient variable → substitution
matching (or easily-matched) coefficients → elimination
Infinitely many solutions
the two equations are equivalent
one equation is just a scaled version of the other — same ratio, including the constant
No solution
matching coefficients, different constants
parallel lines — they never intersect
Graphs ↔ solutions
# of solutions = # of intersection points
1 = crossing lines  ·  0 = parallel  ·  ∞ = same line
Word problems
translate 2 given facts into 2 equations
then solve using substitution or elimination
Combined-expression shortcut
asked for a + b or a − b (not a, b separately)?
add/subtract the equations directly — skip solving for each variable
System with a nonlinear equation
isolate a variable in the linear equation
substitute it into the nonlinear one, then solve
Finding an intersection point
set the two expressions for y equal
solve for x, then plug back in to get y
WATCH OUT — "Equivalent" doesn't mean identical-looking. 6x + 4y = 10 and 3x + 2y = 5 look different but are the same line (divide the first by 2) — that system has infinitely many solutions, not one.
