01 Formulas
Linear model form
\(y = mx + b\)
m = rate of change  ·  b = starting value
Meaning of the y-intercept
\(b\) = value of \(y\) when \(x = 0\)
the initial amount — before any time has passed, before anything is sold, etc.
Meaning of the slope
\(m\) = change in \(y\) per 1 unit of \(x\)
a rate — dollars per year, gallons per minute, miles per hour...
Interpreting f(a) = b
describe the input and output together
"when [input] is a [units], [output] is b [units]"
Change over an interval
\(\Delta y = m \times \Delta x\)
multiply the rate by however much x actually changes
Reverse interpretation
\(\Delta x = \dfrac{\Delta y}{m}\)
take the reciprocal of the slope to go from a Δy to a Δx
Two-variable models
\(ax + by = c\)
check units: each term must match the units of c
Reading a model from a graph
intercept = where the line crosses the axis
slope = rise / run between any two points on the line
Interpreting an ordered pair
\((a, b)\) on the model
"when the input quantity is a, the output quantity is b"
Combination / budget models
intercepts = max of one item when the other is 0
e.g. entire budget spent on just one product
Avoid context traps
match the variable's actual definition
a plausible-sounding unit is wrong if it wasn't how the variable was defined
WATCH OUT — The most common wrong answer on these questions "sounds right" but describes the wrong variable or the wrong units. Always re-read exactly how each letter was defined in the problem before picking an interpretation.
